# BlightFall website roadmap

This is a studio-level roadmap. BlightFall is both the intended name of the independent development
studio/team and the name of its current flagship Roblox game. The roadmap does not claim
incorporation, approve a legal entity, or authorize public facts that have not been confirmed.

## Phase 0 — Verified pre-launch link hub

- Retain `/links/` as the permanent official-link destination. **Implemented.**
- The Roblox group, YouTube, TikTok, Instagram, X, and Bluesky are confirmed and enabled. The public
  Roblox game and trailer/gameplay destinations remain pending confirmation.
- Continue using only approved production assets. **Implemented for the current release.**
- GitHub Pages is the current static host with automated production deployment from `main`.
- Approve a privacy-conscious analytics provider and update the privacy page before activation.
- The custom domain and HTTPS endpoint are active; preserve all existing mail records in any future
  DNS work.

## Phase 1 — Studio information architecture

The foundational home, studio, project index, flagship project, news, contact, and links routes are
implemented. Future work in this phase is approved content expansion rather than structural rebuild.

- Home: introduce the independent BlightFall studio and feature the flagship game.
- Projects/Games: create a scalable project index, initially containing the BlightFall game.
- BlightFall: create a dedicated game area for overview, gameplay, world, media, updates, and
  community links.
- About the Studio: add only approved background, creative direction, values, and development
  approach.
- Team: add founding members only after each name, role, biography, image, and link is approved.
- News/Development: point to the official Discord as the current announcement source while retaining
  a separate model for a future approved website archive. **Implemented.**
- Contact: publish approved direct-email routes for general, business, press, support, and privacy
  inquiries. **Implemented.** A hosted form remains deferred pending its privacy and operational
  design.
- Keep `/links/` and `/privacy/` stable while the broader site grows around them.

## Phase 2 — Flagship game marketing

- Expanded game hero and approved trailer
- Public-safe overview and approved gameplay features
- Screenshot and media gallery
- Optional rotating galleries for future approved key art and screenshots, with a static and
  reduced-motion fallback
- Approved sections for the world, races, classes, combat, and party systems
- Release status, platform availability, and play/follow/favourite actions
- Discord community callout

All implementation-specific text remains pre-alpha and requires current project approval.

## Phase 3 — Studio news and development updates

- Curated republication of approved Discord announcements on the public website
- Markdown content collections with separate studio and project records
- Categories, tags, article routes, RSS, and article sharing metadata
- Build-pipeline support for scheduled publication
- Optional headless CMS evaluation only if maintenance needs justify it

## Phase 4 — Media and press resources

- Trailer and video gallery
- Screenshot gallery
- Downloadable approved logo package
- Press kit and fact sheet
- Approved studio and project descriptions
- Approved press and creator contact route

## Phase 5 — Community and support

- Public-safe FAQ
- Community guidelines and Discord information
- Support, bug-reporting, and Roblox-audience safety directions
- Approved contact route
- Credits and acknowledgements

## Phase 6 — Launch support

- Approved release countdown and launch-day game presentation
- Confirmed Roblox “Play now” deep link
- Patch notes and changelog
- Service-status notice area and temporary announcements
- Campaign landing pages, QR codes, and stable short routes
- Graceful messaging when Roblox or another external service is unavailable

## Phase 7 — Optional integrations

- Cached, approved Roblox game information
- Player or favourite counts only if reliable, privacy-appropriate, and approved
- Newsletter signup with consent and data-handling review
- Localization framework and additional languages
- Privacy-preserving video embeds and approved social highlights
- Merchandising or recruitment links only if those programmes are approved
- Public JSON endpoint containing only approved public-site information

The private production calendar and internal operational systems are permanent non-features of the
public website and must not be embedded, mirrored, or exposed.
